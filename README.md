# Swissôtel Care & Rewards MVP

Русскоязычный MVP-бот для сотрудников отеля: регистрация, адаптация, обращения, задания с баллами, каталог наград и форма отзывов гостей.

## Требования

- Python 3.11+
- Telegram Bot Token (для запуска бота)

## Быстрый запуск на Windows

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
Copy-Item .env.example .env
# Вставьте собственный токен в BOT_TOKEN. Реальных токенов в проекте нет.
py run_bot.py
```

В отдельном терминале запустите веб-сервис отзывов:

```powershell
.\.venv\Scripts\Activate.ps1
py run_web.py
```

Форма отзывов: http://127.0.0.1:8000/reviews
API документация: http://127.0.0.1:8000/docs

## Конфигурация

Все настройки находятся в `.env`. `ADMIN_TELEGRAM_IDS` — числовые Telegram ID через запятую. Пользователи из этого списка получат роль администратора при регистрации. Для QR-кода сотрудника заполните `BOT_USERNAME` именем бота без символа `@`; без него QR содержит служебную ссылку `swissotel://employee/ID`.

## Новые возможности

- В разделе «🎯 Задания» выполненные задания отмечаются отдельно, а кнопка «🏁 Отметить всё выполненным» начисляет баллы за все доступные задания без повторного начисления.
- В каталоге появились дополнительные награды: питание, wellness-скидки, сертификаты, стажевые подарки, обучение и привилегии.
- Номер комнаты обязателен в форме гостя и API отзывов.
- Сотрудник может получить свой QR-кнопкой «📱 Мой QR». Руководитель и администратор могут открыть «📱 QR персонала» и создать QR для выбранного сотрудника.
- Персонал отмечает уборку места кнопкой «🧹 Отметить уборку». Отзывы по совпавшему номеру или зоне привязываются к последнему сотруднику, отметившему это место, и отправляются ему в Telegram; за оценки 4 и 5 автоматически начисляются 5 или 10 баллов один раз за отзыв.
- Раздел «💬 Мои отзывы» показывает отзывы и время их отправки, а «⚙️ Администрирование» позволяет администратору менять роли пользователей.
- История отметок уборки доступна на сайте: http://127.0.0.1:8000/cleaning-history

## База данных

SQLite создаётся автоматически. При первом запуске загружаются демонстрационные сотрудники, задания и награды. Повторный seed не перезаписывает существующие данные.

## Основные API-запросы

```powershell
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/reviews -ContentType 'application/json' -Body '{"guest_name":"Гость","room_number":"101","rating":5,"comment":"Отличное обслуживание"}'
Invoke-RestMethod http://127.0.0.1:8000/api/reviews
```

## Тесты

```powershell
py -m pytest -q
```

Начисление баллов за задания и списание баллов за награды защищены уникальными ключами идемпотентности, поэтому повторная операция не начисляет и не списывает средства дважды.
